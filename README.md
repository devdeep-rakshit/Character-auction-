# Character Auction

A mobile-friendly character auction game for hosting a draft with friends.

## 🌐 Live Website

**Play the website:** https://devdeep-rakshit.github.io/Character-auction-/

## 📦 Source Code

Browse the project files in this repository: https://github.com/devdeep-rakshit/Character-auction-

## 🚀 How to Play

1. Open the live website on your phone or computer.
2. Set up the players and their starting budgets.
3. Run the character auction, placing bids or skipping when it is your turn.
4. Track each player's remaining budget as the auction progresses.
